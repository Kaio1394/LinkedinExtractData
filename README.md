# LinkedinExtractData

> A personal project to practice **Java** and **Selenium WebDriver** by automating data extraction and navigation on LinkedIn.

---

## 🚀 Overview

**LinkedinExtractData** is a study-oriented project developed to improve skills in **web automation** using Java and Selenium.  
The goal is to explore techniques such as:

- Navigating between LinkedIn pages
- Interacting with web elements (buttons, inputs, etc.)
- Extracting and processing structured data
- Implementing reusable helper classes and clean automation patterns

Although this project is not designed for production use, it serves as a valuable sandbox to deepen understanding of automation frameworks, browser drivers, and code structure in Java.

---

## 🧩 Tech Stack

- **Language:** Java 17
- **Automation Framework:** Selenium WebDriver
- **Build Tool:** Maven
- **Logging:** SLF4J + Logback
- **Driver Management:** WebDriverManager
